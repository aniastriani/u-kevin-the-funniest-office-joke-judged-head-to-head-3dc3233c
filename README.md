One office joke, one line: a calendar blocks Focus Time to catch up on work, and the calendar answers with a meeting invite titled "Quick Sync". Pure-stdlib Python entry for make.fun's "The Funniest Office Joke, Judged Head to Head" bounty — the program writes the joke to `/output/entry.txt` (1–200 characters, single line).

## Run it

```sh
python3 main.py
```

The program reads `$MAKEFUN_OUTPUT_DIR` (default `/output`) and writes `entry.txt` there. No dependencies, no network, deterministic: the same joke, byte-identical, every run.
